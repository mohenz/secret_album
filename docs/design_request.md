## 1. 한 문장 요약

> **사진 전시실에 들어온 느낌의 개인 갤러리.** 화면을 여는 순간 사진이 가장자리까지 가득 차고, 글자와 버튼은 사진을 방해하지 않을 만큼만 존재한다. 관리 기능은 필요할 때만 꺼내 쓰는 뒷방이다.

## 2. 이번 시안에서 반드시 바꿀 것

### 2.1 하지 말 것 (v0.1 시안에서 나온 업무형 요소)

| 금지 | 대신 |
|---|---|
| 좌측 사이드바 내비게이션 | 사진 위에 떠 있는 얇은 상단 헤더, 스크롤하면 사라짐 |
| 카드 테두리·배경이 있는 앨범 카드 | 테두리 없는 커버 사진 자체가 카드. 제목은 사진 아래 또는 사진 위 한 줄 |
| 사진 수·앨범 수·저장 용량 같은 통계 숫자 강조 | 숫자는 작고 흐리게, 제목 옆 보조 정보로만 |
| 상태 배지(`나만 보기`, `공유 중`) 상시 표시 | 감상 화면에서는 숨김. 편집 모드에서만 표시 |
| 항상 펼쳐진 필터·정렬 바 | 헤더의 검색 아이콘과 앨범 목록 상단의 작은 정렬 메뉴 하나 |
| 균일한 정사각 썸네일 격자 | 원본 비율을 살린 저스티파이드(행 맞춤) 레이아웃과 에디토리얼 모자이크 |
| 흰 배경 + 파란 버튼이 가득한 화면 | 어두운 전시실 톤, 파란색은 포커스 표시와 편집 모드의 주요 버튼에만 |
| 업로드·선택·삭제 버튼이 감상 화면에 상시 노출 | `편집 모드`에 들어갔을 때만 표시 |

### 2.2 목표 무드

- **어두운 전시실**: 배경은 거의 검정에 가까운 뉴트럴, 글자는 부드러운 회백색. 사진 외에는 색이 없다.
- **사진 전시 도록 / 사진가 포트폴리오**: 큰 제목, 넉넉한 여백, 사진 한 장을 화면 전체폭으로 보여 주는 "쉼표" 구간.
- **조용한 인터페이스**: 아이콘은 가늘고 작게, 버튼은 배경 없는 고스트 형태. 조작 요소는 사진 위에 올라가도 거슬리지 않아야 한다.

## 3. Bloom 표준 적용 방식

화면을 두 영역으로 나누어 적용한다.

| 영역 | 해당 화면 | Bloom 적용 |
|---|---|---|
| **감상 영역** | 잠금 화면, 홈, 앨범 목록, 앨범, 모델, 사진 뷰어, 검색 결과, 즐겨찾기 | 한국어·접근성·Lucide·Pretendard·4px 간격·Radix 복합 UI는 그대로 지킨다. **시각 표현은 3.1 예외를 적용**한다 |
| **관리 영역** | 편집 모드, 업로드, 모델·앨범 등록 폼, 휴지통, 설정 | Bloom 표준을 그대로 적용한다(업무형 UI 허용). 다만 감상 영역과 같은 다크 톤을 유지한다 |

### 3.1 감상 영역 표준 예외 (승인 요청)

Bloom 3.2·15장에 따라 사유·영향·종료 조건을 기록한다. 아래 예외는 사용자 승인 후 확정한다.

| 번호 | 예외 내용 | 사유 | 영향 범위 | 종료 조건 |
|---|---|---|---|---|
| E1 | **다크 테마를 기본값**으로 하고, 라이트 테마는 설정에서 선택 | 사진 감상 시 밝은 배경은 눈부심과 색 인지 왜곡을 일으킴 | 전체 화면 기본 테마 | 사용자가 라이트 기본을 원할 때 |
| E2 | 사진 뷰어 배경은 테마와 무관하게 **어두운 색 고정** (`viewer-background` 토큰을 Light/Dark 양쪽에 같은 값으로 정의) | 라이트 테마에서도 사진 감상 품질 유지 | 사진 뷰어 | 없음(영구 예외) |
| E3 | 사진·커버 이미지의 **모서리 반경 0** | 사진을 잘라내지 않고 전시물처럼 보이게 함 | 사진·커버 이미지만. 버튼·입력·Dialog는 표준 반경 유지 | 없음(영구 예외) |
| E4 | **디스플레이 제목 크기 확장**: 앨범·모델 제목 모바일 32/40px, 데스크톱 56/64px, 굵기 300~500 (Pretendard Variable 유지) | 표준 최대 24px로는 도록형 표지 구성이 불가능 | 홈 히어로, 앨범·모델 상단 제목만. 본문·UI 문구는 표준 크기 | 없음(영구 예외) |
| E5 | 사진 위 글자 가독성을 위한 **하단 어둡게 처리(스크림)** — 검정 0%→60% 선형 그라데이션 | 장식이 아니라 사진 위 글자 대비(WCAG AA) 확보용 | 커버 위 제목, 뷰어 상·하단 컨트롤 영역 | 없음(영구 예외) |
| E6 | 사진 그리드의 **좌우 여백 0(가장자리까지 채움)**, 사진 사이 간격 2~4px | 갤러리형 몰입감 | 사진 그리드만. 글자가 있는 영역은 좌우 16px 이상 유지 | 없음(영구 예외) |

| E7 | **사이트 UI 문구를 영어로** 작성하고 날짜·숫자는 `en-US` 형식을 쓴다 (Bloom 5장 한국어 우선의 예외) | 2026-09-26 사용자 지시 | 화면 문구, 화면에 표시되는 API 오류 메시지, `<html lang="en">` | 사용자가 한국어 UI를 요청할 때 |

예외가 아닌 것(반드시 지킬 것): 문구 원칙(구체적인 버튼 문구, 원인과 다음 행동을 담은 오류 메시지), Lucide 아이콘, Pretendard 글꼴, Radix 기반 Dialog·Dropdown·Sheet, 의미 기반 색상 토큰, 조작 영역 크기(데스크톱 40px·모바일 44px), 보이는 포커스 표시, `alt` 텍스트, `prefers-reduced-motion`, Hover에만 의존하지 않는 정보 접근.

## 4. 정보 구조

```text
잠금 화면
└─ 홈 (대표 앨범 히어로 → 최근 앨범 모자이크 → 모델)
   ├─ 앨범 목록 → 앨범 → 사진 뷰어
   ├─ 모델 목록 → 모델 → 앨범 / 사진 뷰어
   ├─ 즐겨찾기
   ├─ 검색 (전체 화면 오버레이)
   └─ 메뉴 ─ 편집 모드 · 업로드 · 휴지통 · 설정 · 잠그기   ← 관리 영역
```

헤더 메뉴는 `앨범`, `모델`, `즐겨찾기` 세 개와 검색·화면 가리기·메뉴 아이콘만 둔다.

## 5. 감상 영역 화면 (1차 시안 대상)

각 화면은 모바일(390px)과 데스크톱(1440px) 시안을 만든다. 테마는 다크 기본, 라이트는 홈·앨범 2화면만 참고용으로 제작한다.

### 5.1 잠금 화면

- 검정 배경 중앙에 작은 사이트 이름과 비밀번호 입력 하나. 사진·모델명은 절대 노출하지 않는다.
- 입력에는 보이는 Label(`비밀번호`), 버튼은 `잠금 해제`.
- 오류: `비밀번호가 맞지 않습니다. 다시 입력해 주세요.`
- 최초 로그인(아이디 + 비밀번호 + 2단계 인증)도 같은 톤으로 한 화면씩 구성한다.

### 5.2 홈

1. **히어로**: 대표 앨범 커버 한 장이 화면 전체(모바일 세로 100vh, 데스크톱 85vh)를 채운다. 좌하단에 앨범 제목(E4 크기), 모델명·촬영일 한 줄, `앨범 보기` 링크. 하단 스크림(E5).
2. **최근 앨범**: 크기가 다른 커버 3~5개로 구성한 비대칭 모자이크. 큰 커버 1개 + 작은 커버 여러 개. 각 커버 아래에 앨범명(16px)과 모델명·촬영일(13px, 흐리게).
3. **모델**: 세로 3:4 인물 사진을 가로로 스크롤하는 한 줄. 사진 아래 이름만.
4. **쉼표 사진**: 섹션 사이에 즐겨찾기 사진 한 장을 전체폭으로 배치(선택).

### 5.3 앨범 목록

- 2열(모바일)·3열(데스크톱) 커버 그리드, 커버는 4:5 세로 비율, 사진 사이 간격 4px, 좌우 여백 0(E6).
- 커버 아래에 앨범명, 그 아래 `한서윤 · 2026년 9월 12일` 한 줄.
- 상단에는 화면 제목 `앨범`과 오른쪽의 작은 정렬 메뉴(`최근 촬영순`/`최근 추가순`/`이름순`) 하나만 둔다.

### 5.4 앨범

감상 경험의 중심 화면이다.

1. **표지**: 커버 사진 전체폭 + 앨범 제목(E4) + `한서윤 · 서울 성수동 · 2026년 9월 12일 · 148장`.
2. **설명**(있을 때만): 최대 폭 640px, 16/26px 본문.
3. **사진 흐름**: 원본 비율을 유지한 저스티파이드 레이아웃(행 높이 모바일 160px·데스크톱 280px 기준), 사진 사이 2~4px. 약 20장마다 한 장을 전체폭으로 크게 보여 주는 쉼표 구간을 둔다(소유자가 지정 가능).
4. **다음 앨범**: 맨 아래에 같은 모델의 다른 앨범 커버 하나를 크게.
- 상단 헤더 오른쪽에 `슬라이드쇼`(Play 아이콘 + 글자) 하나만 둔다.
- 데스크톱에서 사진에 마우스를 올리면 즐겨찾기 하트만 살짝 나타난다. 같은 기능은 뷰어에서도 제공(Hover 의존 금지).

### 5.5 모델

- **포트폴리오형 표지**: 데스크톱은 좌측에 세로 대표 사진(화면 높이), 우측에 이름(E4)·활동명·짧은 소개. 모바일은 대표 사진 전체폭 + 아래 이름.
- 아래로 모델의 앨범 커버들(5.3과 같은 형식), 그 아래 `모든 사진` 저스티파이드 흐름.
- 통계 숫자는 이름 아래 `앨범 12개 · 사진 1,248장` 한 줄로만.

### 5.6 사진 뷰어

- 어두운 고정 배경(E2), 사진은 화면에 맞춤.
- 썸네일을 누르면 그 자리에서 사진이 확대되며 뷰어로 이어지는 전환(250ms, `transform`·`opacity`). `prefers-reduced-motion`이면 즉시 표시.
- 컨트롤은 상단에 닫기·위치(`12 / 148`)·즐겨찾기·정보·더보기만. 3초간 입력이 없으면 사라지고, 움직이거나 탭하면 다시 나타난다. 키보드 포커스가 있을 때는 숨기지 않는다.
- 이동: 좌우 스와이프, `←` `→`, 데스크톱 화면 양옆 이전/다음 버튼. 확대: 핀치, 더블 탭, 휠.
- 정보(`I` 키 또는 정보 버튼): 데스크톱 우측 패널, 모바일 하단 시트. 촬영일, 모델, 앨범, 카메라·렌즈·노출, 태그, 메모.
- 슬라이드쇼: `Space`로 재생/정지, 간격 3·5·10초, 사진 사이 부드러운 페이드(300ms).
- 닫으면 원래 썸네일 위치로 돌아가고 포커스도 그 썸네일로 복귀.

### 5.7 검색

- 헤더 검색 아이콘을 누르면 전체 화면 어두운 오버레이 + 큰 입력창(24px).
- 입력하면 아래에 `모델`·`앨범`·`태그` 결과를 사진 썸네일과 함께 보여 준다. 결과 없음: `‘성수동’에 맞는 사진이 없습니다. 다른 검색어를 입력해 보세요.`

### 5.8 즐겨찾기

- 저스티파이드 사진 흐름 하나. 비어 있을 때: `아직 즐겨찾기한 사진이 없습니다. 사진을 볼 때 하트를 눌러 모아 보세요.`

## 6. 관리 영역 (2차 시안 대상)

감상 화면에서 관리 기능을 걷어 내는 대신, 아래처럼 한곳으로 모은다. Bloom 표준 UI를 그대로 쓰되 다크 톤을 유지한다.

- **편집 모드**: 앨범·모델 화면의 메뉴에서 `편집` 선택 시 진입. 상단에 `편집 중` 표시와 `완료` 버튼, 사진마다 선택 체크박스(40/44px 영역), 하단에 일괄 작업 바(`즐겨찾기`, `태그 편집`, `다른 앨범으로 이동`, `커버로 지정`, `쉼표 사진으로 지정`, `휴지통으로 이동`). 드래그로 순서 변경(키보드 대체: `앞으로`/`뒤로 이동`).
- **업로드**: 화면 어디에 파일을 끌어 놓아도 전체 화면 드롭 영역이 나타난다. 이후 모델·앨범 선택 시트와 파일별 진행 목록(`대기 중`, `업로드 중…`, `완료`, `실패` — 아이콘+글자).
- **모델·앨범 등록/수정**: 우측 Sheet 폼. 버튼 문구 `모델 등록`, `앨범 만들기`, `변경사항 저장`.
- **휴지통**: 30일 보관(결정 필요), `복원`/`영구 삭제`. 휴지통 이동은 Toast `실행 취소`(5초), 영구 삭제는 AlertDialog(`사진 12장 영구 삭제`).
- **설정**: 보안(비밀번호, 2단계 인증, 자동 잠금 시간, 접속 기기), 표시(테마, 썸네일 가리기 기본값, 뷰어 컨트롤 숨김 시간), 저장 공간.

## 7. 프라이버시 기능

감상 톤을 해치지 않는 형태로 디자인한다.

| 기능 | 요구사항 |
|---|---|
| 화면 가리기 | 헤더의 `EyeOff` 아이콘 또는 `Shift + H`로 즉시 불투명한 검정 화면 + 작은 사이트 이름. 다시 누르면 복귀 |
| 썸네일 가리기 모드 | 모든 사진을 흐리게(블러) 처리, 누른 사진만 선명하게 |
| 자동 잠금 | 설정한 시간 동안 입력이 없으면 잠금 화면. 30초 전 작은 Toast 안내 |
| 중립적 탭 정보 | 브라우저 탭 제목·파비콘에 사진 내용·모델명을 노출하지 않음 |
| 백그라운드 가림 | 탭이 백그라운드로 가면 콘텐츠를 가림 |

## 8. 시각 기준값

| 항목 | 값 |
|---|---|
| 배경(다크) | 뉴트럴 계열 가장 어두운 단계(`neutral-950` 수준). 감상 영역 전체 공통 |
| 글자 | 제목 `foreground`, 보조 정보 `muted-foreground` |
| 강조색 | Blue `primary` — 포커스 링, 편집 모드 주요 버튼, 선택 표시에만 사용 |
| 글꼴 | Pretendard Variable 단일. 디스플레이 제목은 가는 굵기(300~500), 본문 400 |
| 아이콘 | Lucide, 선 굵기 1.5~2, 헤더 아이콘 20px(클릭 영역 40/44px) |
| 사진 간격 | 2px(앨범 흐름), 4px(커버 그리드) |
| 모서리 | 사진 0(E3), 버튼·입력·시트 표준 10px |
| 그림자 | 사용하지 않음 |
| 모션 | 화면 전환 250ms, 컨트롤 표시/숨김 150ms, `transform`·`opacity`만 |

## 9. 반응형

| 구간 | 커버 그리드 | 앨범 사진 흐름 행 높이 |
|---|---|---|
| 모바일 360~767px | 2열 | 약 160px |
| 태블릿 768~1279px | 3열 | 약 220px |
| 데스크톱 1280px 이상 | 3~4열 | 약 280px |

- 모바일 헤더는 로고 + 검색 + 메뉴 아이콘만. 하단 탭바는 두지 않는다(사진 영역 확보).
- 뷰어는 `env(safe-area-inset-*)` 반영.

## 10. 접근성

- 사진 `alt`: 소유자가 입력한 설명, 없으면 `한서윤 · 성수동 촬영 · 2026년 9월 12일`.
- 사진 그리드는 방향키로 이동, `Enter`로 뷰어 열기. 본문 바로가기 링크 제공.
- 어두운 배경과 사진 위에서도 보이는 포커스 링(흰 테두리 + 파란 링 2중).
- 사진 위 글자는 스크림(E5)으로 WCAG AA 대비 확보.
