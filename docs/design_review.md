# 외부 디자인 시안 1차 검토

- 검토일: 2026-09-26
- 기준: `docs/design_request.md` v0.2, `design/nocturne_monograph/DESIGN.md`
- 대상: `design/_1`~`design/_8`

## 채택

- 거의 검정인 전시실 배경, 회백색 텍스트, 사진의 각진 모서리
- 큰 디스플레이 제목과 절제된 메타데이터
- 감상 화면의 전체폭 사진, 얇은 간격, 하단 스크림
- 관리 조작을 감상 흐름과 분리하는 방향

## 수정 후 채택

- `_1`~`_4`의 홈·앨범·뷰어·잠금 화면 구조는 정보 밀도를 낮추고 Pretendard·Lucide로 교체한다.
- Nocturne 팔레트는 Bloom 의미 토큰 이름으로 매핑한다. 파란색은 포커스와 편집 상태에만 사용한다.
- 이미지 확대 모션은 250ms, `prefers-reduced-motion`에서는 제거한다.

## 채택하지 않음

- `_5`~`_8`의 상시 좌측 사이드바, 통계·필터 중심 관리 화면
- Material Symbols, Geist, 외부 폰트·이미지 의존성
- 감상 화면에 상시 노출되는 선택·업로드·삭제 조작
- 사진 카드의 테두리·그림자·둥근 모서리

## 구현 기준

초기 화면은 사진이나 모델 정보를 노출하지 않는다. 인증 구현 전에는 중립적인 상태 화면만 제공하고, 이후 감상 화면은 `_1`~`_4`의 전시실 분위기를 참고하되 `docs/design_request.md`의 E1~E6과 접근성 규칙을 우선한다.


## 2차 정렬 (2026-09-26)

- `design/_1`~`_8`의 `screen.png`는 이미지가 아니라 "FIFE Image failed to fetch" 오류 텍스트다. 시안은 `code.html`을 브라우저로 열어 확인한다.
- 사용자 지적("가이드 받은 디자인과 많이 다르다")에 따라 감상 화면을 `_1`~`_4`에 맞췄다.
  - 헤더: 자물쇠+브랜드, 가운데 메뉴와 밑줄, 오른쪽 검색·화면 가리기·슬라이드쇼·메뉴·계정 아바타
  - 홈(`_1`): 제목만 있는 히어로와 화살표 버튼·스크롤 안내, 큰 커버 + 넓은 커버 + 세로 커버 2, 전체 폭 쉼표 사진, 모델 4명, 푸터
  - 앨범(`_2`): 표지 위 뒤로 가기와 Play slideshow·Edit mode 알약 버튼, 격자 밀도 전환, 즐겨찾기 원형 표시, 시리즈 계속 보기 카드, 보관소 푸터
  - 뷰어(`_3`): 왼쪽 위 원형 닫기, 가운데 위치 알약, 원형 버튼(화면 가리기·재생+간격·즐겨찾기·정보·내려받기), 원형 화살표, 슬라이드쇼 진행 막대
  - 잠금·로그인(`_4`): 자물쇠 배지, 큰 제목, 카드 안 비밀번호(보기 전환)와 자물쇠 아이콘 버튼, 화면 가리기 버튼, 보관소 푸터
- 유지한 Bloom 규칙: Pretendard(시안의 Geist 대신), Lucide, 영어 UI(E7), 조작 영역 크기, 포커스 표시.

## 3차 정렬: Studio 관리 화면 (2026-09-26)

사용자 지적("관리화면이나 잘 만들어놔")에 따라 관리 화면을 `_5`~`_8`에 맞춰 Studio로 다시 만들었다.

- 공통 틀: 왼쪽 사이드바(브랜드+STUDIO, 메뉴 5개, 전시실로 돌아가기, 저장 공간), 위쪽 경로 표시·Secure session·화면 가리기·계정 메뉴. 1023px 이하에서는 사이드바가 서랍으로 바뀐다.
- Archive overview(`/manage/index.html`): 통계 4개, 최근 업로드 10장, 저장 공간·사진 처리 현황, 앨범 목록.
- Photo library(`/manage/photos.html`, `_5`·`_8`): 모델 탭, 검색·앨범·정렬 필터와 필터 칩, 카드/목록 전환, 체크 선택, 표지·전체 폭 표시, 즐겨찾기, EXIF, 아래쪽 일괄 작업 막대(즐겨찾기·태그·앨범 이동·표지·전체 폭·내려받기·휴지통+되돌리기).
- Quick upload(`_6`·`_7`): 드롭존(아이콘 배지, Ctrl+V 표시, 파일 선택·붙여넣기)과 오른쪽 대상 패널(모델 선택→앨범). 업로드 방식은 cinetube 퀵등록 표준을 그대로 유지한다.
- Trash·Settings도 Studio 틀을 쓴다.
- 검증: E2E 85개(Studio 11개, 모바일 390px 넘침·44px 조작 영역 포함) 통과.
